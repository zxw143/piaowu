# 《醉龍》電子邀請票

嘉賓透過專屬連結亮票。工作人員登入後可新增嘉賓、複製邀請連結、查閱名單並掃碼核銷。每張票供一人使用，核銷後票頁會自動切換到歡迎頁。

## 本機啟動

需要 Node.js 24 或以上。在專案目錄執行以下指令（Windows PowerShell 可用 `npm.cmd`）：

```sh
npm ci
npm run staff -- gate01
npm start
```

建立帳號時終端機會顯示隨機密碼。開啟 [工作人員登入](http://127.0.0.1:3000/login)，使用剛才的帳號密碼登入。可為每位驗票員分別建立帳號，以便追查核銷紀錄。

如需重設密碼，執行 `npm run staff -- gate01 --reset`。程式會撤銷該帳號先前的登入狀態。

## 兩台手機試用

1. 工作人員登入後填寫嘉賓姓名，按「生成邀請票」，複製連結發給測試手機。
2. 嘉賓打開連結，點票面右下角的二維碼或「放大驗票碼」。對方可看到二維碼和可手輸的票號。
3. 工作人員按「開啟相機」並掃描。掃碼後顯示結果，按「掃下一張」繼續。也可輸入票號核銷。
4. 保持嘉賓端票頁開啟，約兩秒後應跳至歡迎頁。重掃同一張票時，後台應顯示首次核銷時間。

## 部署

- 由反向代理為站點提供 HTTPS，並把流量轉發到 Node 服務。參照 `.env.example` 設定 `.env` 中的 `APP_ORIGIN` 為公開的 HTTPS 網址。由該網址登入後再複製正式邀請連結，手機相機也需要可用的 HTTPS 網址。
- `APP_DB` 預設指向 `data/tickets.sqlite`。部署時放在持久化磁碟上並定期用 SQLite 備份工具備份。建立帳號和啟動伺服器時使用相同的資料庫設定。
- 驗票端須能連上伺服器。嘉賓端如果已經載入二維碼，臨時斷網時仍然可以亮票，恢復連線後票頁會繼續查詢。演出前用正式網址在場地測試 iPhone、Android、微信內開啟、相機掃碼和弱網。
- 臨時核銷成功頁位於 `public/welcome.html`，劇組確定內容後可直接修改。

執行 `npm test` 可驗證登入權限、出票重試、同票重掃與嘉賓頁面的跳轉條件。
